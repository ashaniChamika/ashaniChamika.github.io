# Ashani Chamika — Professional Portfolio

A responsive personal portfolio website built from the supplied portfolio ZIP.

## Included
- Responsive single-page portfolio
- Professional hero/profile section
- About, skills, education/career journey
- Project showcase with filters
- Project case-study modal with screenshots
- Certificates section
- Contact / social links
- CV download
- Light/dark theme toggle
- Scroll progress indicator and subtle reveal animations

## Run locally
Open `index.html` in a browser.

For the best local development experience, use VS Code with Live Server.

## Main files
- `index.html`
- `assets/css/style.css`
- `assets/js/app.js`
- `assets/images/profile.png`
- `assets/docs/Ashani_Chamika_CV.pdf`
